# Mídia Seara

Aplicativo independente do ecossistema Assembleia de Deus Seara.

## Etapa atual
Estrutura HTML + CSS + JavaScript, PWA e armazenamento local para validação do fluxo próprio do aplicativo.

## Regra arquitetural
Este aplicativo será conectado ao SEARA CENTRAL somente depois que suas funções próprias estiverem validadas.

## Próximas integrações
- autenticação futura;
- Supabase;
- envio de programação;
- músicas e observações;
- roteamento automático;
- chat interno contextual;
- sincronização com cultos.
